A — Dedicated "Progress" Tab

Add a 4th tab to the bottom nav. Gamification gets its own full screen: XP bar, badge wall, active challenges, leaderboard all in one place. Most discoverable.

Pros

  • Users know exactly where to go
  • Full canvas for rich content
  • Signals it's a core feature

Cons

  • Adds a tab (more nav weight)
  • Users must leave current screen

B — Embedded in Profile Tab

Profile screen expands to include a gamification section: level card at the top, then badges, quests, and leaderboard as sub-sections. Keeps nav clean.

Pros

  • No extra tab needed
  • Natural home — "my stuff"
  • Simpler navigation

Cons

  • Profile screen gets busier
  • Less prominent / easy to miss

C — Ambient + Profile Hub

XP toasts appear inline after scans, a persistent mini XP bar lives at the top of every screen, and tapping it opens a full gamification hub modal. Discovery is organic.

Pros

  • Gamification feels alive everywhere
  • XP feedback is immediate
  • No nav changes needed

Cons

  • Modal hub can feel buried
  • Mini bar takes screen space
